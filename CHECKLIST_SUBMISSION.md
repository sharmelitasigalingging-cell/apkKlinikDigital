## ✅ Sebelum Submit (centang satu-satu)

- [ ] `npm install` jalan tanpa error
- [ ] `npx expo start` jalan, app kebuka di Expo Go (test login, register, booking, riwayat, foto KTP)
- [ ] `assets/icon.png` & `assets/splash.png` sudah ada (sudah disediakan di project ini)

- [ ] Repo GitHub sudah dibuat, di-set **Public**
- [ ] `git init` → `git add .` → `git commit` → `git push` berhasil
- [ ] `eas login` sudah login ke akun expo.dev
- [ ] `eas build --platform android --profile preview` sudah dijalankan
- [ ] Link APK (GitHub Release atau Google Drive) bisa diakses & APK bisa diinstall

## ⏱️ Sisa Waktu? Prioritas Kalau Mepet

1. **Wajib jalan dulu**: pastikan app ga crash, semua fitur teknis (form, FlatList, AsyncStorage, kamera) berfungsi — ini poin terbesar
2. **Push GitHub** (public!) — walau APK belum selesai build, repo + Expo Snack tetap bisa disubmit duluan
3. **EAS Build** bisa jalan di background sambil isi form Moodle — link APK bisa diedit belakangan kalau build kelar setelah waktu submission (konfirmasi ke dosen dulu)
4. Kalau APK gagal build karena waktu mepet: **Expo Snack jadi bukti utama** kode berjalan
